## Overview

Capacity reviews work best when admins combine the org-level workspace directory with the per-workspace **Limits** tab.

Use the directory to decide which workspace needs attention, then use the limits page to review the local policy and current usage.

---

## Signals That Should Trigger Review

- unusual growth in the workspace directory
- a workspace approaching its current cap
- a workspace that is uncapped but growing faster than expected
- a workspace whose storage level no longer matches its business purpose

## Use The Limits Tab For The Final Decision

Once a workspace looks like it needs capacity attention, use **Limits** to review the actual storage posture.

<Frame caption="Workspace-level limits review">
![Workspace limits review](/images/admin/admin-workspace-limits-live-v2.jpg)
</Frame>

---

## Review Rhythm

1. Weekly: scan the workspace directory for unusual growth.
2. Monthly: review the workspaces with the highest storage pressure.
3. Quarterly: revisit whether unlimited workspaces should stay uncapped.

---

## Best Practices

- Review trend direction, not only absolute size.
- Pair storage reviews with membership and workspace-purpose reviews.
- Do not treat unlimited mode as a substitute for governance.
